# Fonts

Two typefaces, both SIL Open Font Licence 1.1, self-hosted so the site makes
no third-party requests and works with no network beyond its own origin.

- **Source Sans 3** — the body face. The Shetland Wool Week patterns are set
  in Source Sans Pro, which this is the current release of.
- **Oswald** — the display face, standing in for Franchise Bold, which the
  patterns use for their titles and which is not openly licensed.

Both are variable fonts, so one file covers every weight. The latin subset
only; re-fetch from Google Fonts if another script is ever needed.
